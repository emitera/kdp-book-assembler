# UI & Product Design

> Core guidance for responsive, accessible, coherent, and polished application interfaces.

## Use When

- Designing or refining application UI.
- Reviewing responsive layout and visual hierarchy.
- Improving accessibility and visual consistency.

## Do Not Use For

- Business workflow design.
- Backend architecture.
- Design-system governance when `design.system.audit` is required.

## Core Rules

- **Hierarchy First**: Optimize visual hierarchy, readability, and task clarity before decorative effects.
- **Purposeful Motion**: Use micro-interactions only when they improve feedback, continuity, or orientation.
- **Responsive Design**: Design for supported viewport ranges rather than a single fixed layout.
- **Accessibility**: Use semantic interfaces and preserve contrast, keyboard operation, focus visibility, and readable sizing.
